# Design and Simulation of a 4-Bit Magnitude Comparator

## 📌 Project Overview

This project presents the design and simulation of a **4-Bit Magnitude Comparator** as part of the **Digital Logic Design** course. A magnitude comparator is a combinational logic circuit used to compare two 4-bit binary numbers and determine whether one number is **greater than**, **less than**, or **equal to** the other.

The project includes theoretical design, software simulation, hardware implementation, and project documentation.

---

## 🎯 Objectives

- Design a 4-bit magnitude comparator.
- Verify the logic through software simulation.
- Implement the circuit in hardware.
- Compare two 4-bit binary numbers accurately.
- Demonstrate the functionality using simulation and hardware testing.

## 📖 Project Description

The 4-Bit Magnitude Comparator compares two 4-bit binary inputs:

- A = A3 A2 A1 A0
- B = B3 B2 B1 B0

The circuit generates one of the following outputs:

- **A > B**
- **A < B**
- **A = B**

Only one output becomes HIGH at a time, indicating the comparison result.
